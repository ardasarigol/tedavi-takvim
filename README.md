# 💊 Tedavi Takip — Sedef Hastalığı Hatırlatıcı Uygulaması

Sedef hastalığı tedavisinde doz tarihlerini takip etmeyi kolaylaştıran, 
tarayıcı tabanlı bir web uygulaması.

## 🎯 Problem

Sedef hastalığı tedavisinde dozlar 28 gün ve 3 aylık aralıklarla uygulanıyor. 
Hastalar bu tarihleri takip etmekte zorlanıyor ve dozları kaçırabiliyor.

## ✅ Çözüm

Hasta tipi (naif / devamlı) seçimine göre tüm doz tarihlerini otomatik hesaplıyor 
ve `.ics` formatında takvim hatırlatıcısı oluşturuyor.

## 🔧 Özellikler

- Naif ve devamlı hasta için ayrı doz hesaplama mantığı
- Doz gününden 5 gün öncesine kadar günlük hatırlatıcı
- iOS ve Android için ayrı kurulum yönlendirmesi
- Google Analytics ile kullanım takibi
- Sıfır backend — tamamen tarayıcı tabanlı

## 🛠 Teknolojiler

HTML · CSS · Vanilla JavaScript · iCalendar (.ics) · Google Analytics

## 🚀 Kullanım

Projeyi klonlayın ve `index.html` dosyasını tarayıcıda açın.
